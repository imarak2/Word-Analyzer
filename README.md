# Word-Analyzer
A simple word analyzer made in Python.

It will provide info on whatever text you throw into it and report how much of the text consists of:  
- Punctuation  
- Spaces  
- Digits  
- Lowercase letters  
- Uppercase letters

## Sample Output
Welcome to the Word Analyzer!
Type in here to test it out!: Hello World!
Everything looks good! The result is correct! ✅

After careful analysis, here are the results:
Punctuation marks: 1
Digits: 0
Lowercase letters: 8
Uppercase letters: 2
Spaces: 1
Press Enter to exit the program.
## How to run the program
Click on the .exe file, type in your text, and the program will run.
That's it. I did say it's a simple word analyzer.
